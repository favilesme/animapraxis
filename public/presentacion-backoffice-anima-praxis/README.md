# Demo comercial — Backoffice Anima Praxis

Presentación ejecutiva interactiva de 14 pantallas para explicar el sistema integrado de Estrategia, Cultura, Coaching y Liderazgo 360 de Anima Praxis.

## Uso

1. Abra `index.html` en Chrome, Safari, Edge o Firefox.
2. Use las flechas del teclado, la barra espaciadora o los controles visibles.
3. Presione `M` para abrir el menú y `F` para activar pantalla completa.

No requiere instalación, conexión a internet ni servidor. Todos los estilos, interacciones y gráficas están incluidos en `index.html`; los activos oficiales se encuentran en `assets`.

## Alcance de la demo

- Los valores de evaluación son ilustrativos y están marcados como DEMO.
- La presentación no describe una metodología psicométrica.
- Las pantallas simuladas representan el concepto del servicio y no ejecutan operaciones reales.
- El asistente de IA se presenta como apoyo al proceso, no como sustituto del coach.
